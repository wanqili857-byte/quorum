# 独立复核工单 · demo 项目

你是外部审计员，与本项目无关。工作目录是 demo 目录。

## 0. 背景

一个小组做了「造数据 → 跑预测 → 出报告」的流水线。请你独立复核它的产物是否可信。

## 1. 材料

| 文件 | 性质 |
|---|---|
| `project/data/answers.jsonl` | 答案（唯一事实源） |
| `project/data/pred_old.jsonl` | 预测 |
| `project/report.md` | 对外的报告 |
| `project/build.py` | 切分脚本 |
| `project/gate.py` | 作者写的门禁 |

## 2. 审计线

1. **数字**：报告里的每个数字，自己从 `answers.jsonl` + `pred_old.jsonl` 重算一遍。
2. **可复现**：`build.py` 同参数重跑，结果是否相同？
3. **门禁**：`gate.py` 检查的性质，是不是读者以为的那个性质？
4. **反向证伪**：文档里有没有「数字对得上、但归因不成立」的说法？

## 3. 输出

第二节用 `| 严重度 | 位置 | 问题 | 证据 | 建议 |` 表格，每条必须带「我怎么查出来的」。
最后一节写 `## 最脆弱的一环（前三）`。

## 4. 硬约束

只读；数字必须自己算；不复述任何真实业务内容。
